   Issue: PKCS#1 v1.5 padding is deprecated and vulnerable to padding oracle
   Impact: Signature forgery possible with sufficient effort
   Status: Requires crypto library upgrade

HIGH-PRIORITY FINDINGS
================================================================================

4. INSECURE ENTROPY CACHE (HIGH - CWE-276)
   Files: src/pydepguardnext/api/net/entropy_utils.py:15-25
          src/pydepguardnext/api/sign/sign_utils.py:43-53
   Issue: Cache file stored in world-readable temp directory
   Impact: Entropy validation can be bypassed by reading/modifying cache
   Status: Fix requires secure file permissions

5. INFORMATION DISCLOSURE (MEDIUM - CWE-200)
   File: src/pydepguardnext/api/net/key_utils.py:74-91
   Issue: Detailed system information exposed in fingerprinting
   Impact: System fingerprinting reveals exact OS/kernel versions
   Status: Can be fixed by reducing disclosed information

6. GUARD PAGE LOGIC ERROR (MEDIUM - CWE-190)
   File: src/pydepguardnext/api/sign/securemem.py:232
   Issue: Guard page address calculation incorrect on Windows
   Impact: Memory protection bypassed via buffer overflow
   Status: Requires address calculation fix

7. WEAK ENTROPY VALIDATION (MEDIUM - CWE-330)
   File: src/pydepguardnext/api/net/entropy_utils.py:28-31
   Issue: Pattern detection too simplistic, fails to catch sophisticated patterns
   Impact: Weak entropy can pass validation checks
   Status: Requires enhanced pattern detection

8. INFO LEAKAGE IN ERROR HANDLING (MEDIUM - CWE-532)
   File: src/pydepguardnext/api/net/key_utils.py:43-49
   Issue: Internal error details exposed through detailed_msg parameter
   Impact: Sensitive information leaked in error messages
   Status: Requires message handling changes
